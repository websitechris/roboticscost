Questions to ask before you buy

  1. Which features need a higher model? Cheaper versions often lock out programming or add-ons.
  2. How long does the battery last, and what does a spare cost?
  3. Where is it repaired? Shipping a robot abroad for repair is slow and costly.
  4. Does it need the maker's app or cloud? Ask what happens to it if that stops.
